# Database_Design_and_Implementation

### Problem Statement:

To design a relational database systems for improved operational efficiencies and make it easier for the executives to make data-driven decisions to expand nationally by opening several franchise locations.

Currently, the data resides in several systems: accounting software, supplier databases, point of sales (POS) systems, and even spreadsheets. Review the data in all of these systems and design a central database to house all of the data and create the database objects and load them with source data. Finally, create subsets of data that the business partners require, export them, and load them into staging databases using several RDBMS.

### Steps:
- Create an entity relationship diagram (ERD) using the pgAdmin ERD tool
- Normalize tables
- Define keys and relationships
- Create database objects by generating and running the SQL script from the ERD tool
- Create a view and export the data
- Create a materialized view and export the data
- Import data into a MySQL database using phpMyAdmin GUI tool
